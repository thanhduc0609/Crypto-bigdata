Broker Apache Kafka

  • Chế độ: KRaft Mode (3.9+)
  • Cluster Endpoint: localhost:9092
  • Chủ đề (Topic): crypto-trades
  • Phân vùng (Partitions): 3 (P0: BTC, P1: ETH, P2: SOL)
  • Đảm bảo thứ tự: Strict Partition Ordering
⚡

Spark Structured Streaming

  • Phiên bản: Apache Spark 3.5.1 LTS
  • Cơ chế Xử lý: Micro-Batch 5-10s
  • Cửa sổ tính toán: 1-Minute Tumbling Window
  • Dung sai trễ: Watermark 2 Minutes
  • Lọc nhiễu: dropDuplicates(trade_id, symbol)
☁️

AWS S3 Data Lake

  • Định dạng tệp: Apache Parquet (Snappy)
  • Đường dẫn Raw: crypto/raw/trades/
  • Đường dẫn Aggregated: crypto/processed/trades_1m/
  • Phân vùng S3: symbol=... / trade_date=...
  • Đọc Batch: PySpark Batch Reader & Aggregator
🏛

PostgreSQL Data Warehouse

  • Phiên bản Container: PostgreSQL 16 Alpine
  • Port kết nối: 5433 (Tránh xung đột 5432)
  • Mô hình CSDL: Star Schema (Dim & Facts)
  • Business Views: Whales, Hourly, Daily, Order Flow
  • Dung lượng hiện tại: 8 MB
💻

BẢNG LỆNH ĐIỀU KHIỂN HỆ THỐNG (POWERSHELL SCRIPTS)

1. Khởi động Docker (Kafka & PostgreSQL) .\scripts\setup_env.ps1 -DockerUp
2. Chạy Ingestion Producer (WebSocket OKX) .\scripts\setup_env.ps1 -RunProducer
3. Chạy Spark Streaming Engine .\scripts\setup_env.ps1 -RunSpark
4. Đồng bộ ETL S3 vào PostgreSQL Data Warehouse .\scripts\setup_env.ps1 -RunETL
